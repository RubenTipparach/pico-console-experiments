# The console's font: 5x7, one picture per character.
#
# tools/gen_font.py packs this into a const table at build time. Editing a
# glyph means editing the picture, which is the point: hand written hex is how
# a font ends up with a letter nobody notices is wrong.
#
# Format: a line "@X" opens the glyph for character X, then exactly 7 rows of
# exactly 5 characters. '#' is ink, anything else is background. A bare "@" is
# the space glyph, because a trailing space in a text file survives exactly
# until the first editor that trims one. Blank lines and lines starting with
# '#' in column 1 are comments, except inside a glyph, where every line is
# picture.
#
# This charset is the whole charset. A menu name with a character that is not
# here fails the build in tools/gen_library.py rather than drawing as a hole,
# which is the same refusal PicoCrystal's generator makes for the same reason.
