# Type ring: ember > leaf > stone > spark > tide > ember. Five types in a loop
# a player can hold in their head, plus mind, which is even against everything
# and takes double from itself. One rule, no chart to show on a 120 pixel
# screen.
#
# Six meshes serve sixteen species. A mesh is roughly 1.2 KB of flash and a
# tint is three bytes, so an evolution that reuses its base mesh at a larger
# scale and a different tint costs 3 bytes instead of 1200. That is the whole
# reason the roster can be this size on this device.
